# Imagens do app

Coloque aqui os arquivos da logo (PNG com fundo transparente):

- `nome-quiztion.png` — logo horizontal com o texto "QUIZtion" (usada no header
  da tela inicial e no splash).
- `logo-quiztion.png` — apenas o ícone (cérebro), usado no header das demais
  telas.

O app degrada graciosamente se os arquivos não existirem (mostra um texto/ícone
de fallback), então o projeto compila mesmo antes de você adicioná-los.
